Описание проекта

Данный проект посвящён численному вычислению суммы бесконечного ряда:

$$\sum_{n=1}^{\infty} \frac{n+1}{n^3+0{,}06}$$

с заданной точностью $\varepsilon = 10^{-6}$

Цели проекта

  • Вычислить сумму ряда с точностью $\varepsilon = 10^{-6}$
  • Оценить погрешность вычислений
  • Применить методы ускорения сходимости
  • Сравнить результаты различных подходов

Математическое обоснование

Возьмём для примера исходный ряд:

$$\sum_{n=1}^{\infty} \frac{n+1}{n^3+0{,}06}, \quad \varepsilon = 10^{-6}$$

I. Прямое вычисление

1) Интегральный признак Коши

Оцениваем остаток ряда через интеграл:

$$\int_{N+1}^{\infty} \frac{x+1}{x^3+0{,}06} \leq \int_{N+1}^{\infty} \frac{2x}{x^3} = \int_{N+1}^{\infty} \frac{2}{x^2} = 2\cdot\left(-\frac{1}{x}\right)\Bigg|_{N+1}^{\infty} = 2\left(0 - \left(-\frac{1}{N+1}\right)\right) = \frac{2}{N+1}$$

2) Определение количества членов

$$\frac{2}{N+1} \leq \frac{10^{-6}}{2}$$

$$N+1 \geq \frac{4}{10^{-6}} = 4\cdot 10^6$$

$$N \geq 4\cdot 10^6 - 1$$

$$N = 4\cdot 10^6 = 4\,000\,000$$

3) Оценка погрешности

$$A_{S_N^*} = \sum_{n=1}^{N} A_{a_n^*} = N\cdot A_{a_n^*} \leq \frac{\varepsilon}{2}$$

$$A_{a_n^*} \leq \frac{\varepsilon}{2N} = \frac{10^{-6}}{2\cdot 4\cdot 10^6} = \frac{10^{-12}}{8} = 1{,}25\cdot 10^{-13} = 0{,}125\cdot 10^{-12}$$

Требуется 14 верных цифр после запятой

4) Результат

$$S = S_N = 2{,}730549$$

5) Ускорение сходимости

$$S = \lambda B + \sum_{n=1}^{\infty}(a_n - \lambda b_n) = \lambda B + \sum_{n=1}^{\infty} p_n$$

Исходный ряд сходится как $\dfrac{1}{n^2}$, поэтому выбираем:

$$\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6} = B$$

Находим коэффициент $\lambda$:

$$\lambda = \lim_{n\to\infty}\frac{a_n}{b_n} = \lim_{n\to\infty}\frac{(n+1)n^2}{n^3+0{,}06} = \lim_{n\to\infty}\frac{n^3+n^2}{n^3+0{,}06} = \lim_{n\to\infty}\frac{n^3\left(1+\frac{1}{n}\right)}{n^3\left(1+\frac{0{,}06}{n^3}\right)} = 1$$

Вычисляем новый ряд:

$$p_n = a_n - \lambda b_n = \frac{n+1}{n^3+0{,}06} - \frac{1}{n^2} = \frac{n^3+n^2-n^3-0{,}06}{n^2(n^3+0{,}06)} = \frac{n^2-0{,}06}{n^2(n^3+0{,}06)} \sim \frac{1}{n^3}$$

Новый ряд сходится быстрее — как $\dfrac{1}{n^3}$.

1) Оценка остатка

$$\int_{M+1}^{\infty} \frac{n^2-0{,}06}{n^2(n^3+0{,}06)} < \int_{M+1}^{\infty} \frac{x^2}{x^2\cdot x^3} = \int_{M+1}^{\infty} \frac{1}{x^3}\,dx = -\frac{1}{2x^2}\Bigg|_{M+1}^{\infty} = \frac{1}{2(M+1)^2}$$

2) Количество членов

$$\frac{1}{2(M+1)^2} \leq \frac{\varepsilon}{2} = \frac{10^{-6}}{2}$$

$$(M+1)^2 \geq \frac{2\cdot 10^6}{2} = 10^6$$

$$M+1 \geq 1000, \quad M = 1000$$

3) Погрешность

$$A_{S_M^*} = \sum_{n=1}^{M} A_{p_n^*} = M\cdot A_{p_n^*} \leq \frac{\varepsilon}{2}$$

$$A_{p_n^*} \leq \frac{\varepsilon}{2M} = \frac{10^{-6}}{2\cdot 1000} = \frac{10^{-6}}{2000} = 0{,}5\cdot 10^{-9}$$

Требуется 9 цифр после запятой

4) Результат

$$S = S_M = \frac{\pi^2}{6} + \sum_{n=1}^{1000} \frac{n^2-0{,}06}{n^2(n^3+0{,}06)} = 2{,}730547$$

$$P_M = \sum_{n=1}^{1000} \frac{n^2-0{,}06}{n^2(n^3+0{,}06)} = 1{,}085613$$
